# Progress Steps

A five-step visual progress indicator. Open `index.html` in a browser; no build step, server, or network connection is required.

Use **Next** and **Prev** to move between steps. The buttons stop at the first and fifth steps. This is a UI demonstration: it does not collect form data or save progress between visits.
