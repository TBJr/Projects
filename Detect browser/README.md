# Detect browser

A browser-detection demonstration that highlights one of five bundled browser logos: Chrome, Firefox, Edge, Opera, or Safari. Open `index.html` in a browser. No build step, server, or network connection is required.

Detection is based on `navigator.userAgent`. Browsers may change or mask this string, so the result is only a best guess. An unrecognized browser triggers an alert and does not highlight a logo. The browser logos are third-party marks and are not covered by the code credit below.
