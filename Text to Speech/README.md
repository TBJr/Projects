# Text to Speech

Type text, choose a voice, and play it using the browser's speech synthesis feature. The button can pause and resume longer passages.

## Run

Open `index.html` in a browser, enter text, choose an available voice, and select **Convert To Speech**. No server or account is required.

Voice names and availability depend on the browser and operating system. A browser without speech synthesis support cannot play the text. The page does not export an audio file. Poppins is requested from Google Fonts and may fall back when offline.
