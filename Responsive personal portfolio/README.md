# Responsive personal portfolio

A single-page portfolio template with home, about, services, skills, team, and contact sections. It includes a mobile menu, animated role labels, a team carousel, and a scroll-to-top button.

## Run

Open `index.html` in a browser. No build step is required. An internet connection is needed for the CDN libraries and fonts.

## Customize

- Replace the sample name, biography, skills, contact details, and images in `index.html` and `assets/images/` before publishing.
- Update the role labels in `js/script.js`.
- Replace the placeholder links. The contact form currently has no message delivery, and the CV button has no download target.

The page loads Font Awesome, jQuery, Typed.js, Waypoints, Owl Carousel, and Google Fonts from external services. The existing page also contains sample identity and footer credit; review those and the image rights before reusing the template.
