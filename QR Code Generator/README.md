# QR Code Generator

Enter text or a URL and select **Generate QR Code** to display a QR image. Open `index.html` in a browser; no build step or local server is required.

The image is generated by `api.qrserver.com`. Your input is sent to that external service as part of the image URL, so do not use this page for private or sensitive content. Generation requires an internet connection and depends on that service being available. Repeating the same unchanged input does not request another image.
