# Rotating Navigation

A navigation animation demo. Click the menu button to rotate the article panel and reveal the side navigation; click close to return to the article.

## Run

Open `index.html` in a browser. No build step or server is required.

The menu items are display examples rather than working links. The article image is stored in `assets/img/`. Font Awesome 5.15.4 is bundled in `assets/fontawesome-5.15.4-web/` and has its own `LICENSE.txt`. The stylesheet also requests the Lato font, but its current import URL contains a typo, so the browser may use a fallback font.
