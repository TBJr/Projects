# Security policy

These projects are learning and demonstration examples. The current `main` branch is the only version maintained in this repository; older commits and copies are not maintained. There is no guaranteed response time or security support agreement.

The two PHP demos accept uploads or store short links and should be reviewed and hardened for the intended environment before being exposed publicly. Browser demos may rely on external services as described in the [README](README.md).

## Reporting a vulnerability

Please do not post exploit details, credentials, or personal data in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. If it is unavailable, use a private contact method published at [thomasbrown.app](https://thomasbrown.app/). If no private contact method is listed, open a brief public issue requesting one, without including sensitive details.

For ordinary bugs that do not involve sensitive information, use the bug report issue form.
