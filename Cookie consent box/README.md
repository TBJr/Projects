# Cookie consent box

Open `index.html` in a browser. The page uses plain HTML, CSS, and JavaScript.

The prompt offers accept, reject, and custom choices. It saves the decision in a first-party cookie for 180 days. If the cookie cannot be updated, it tries local browser storage for the same period. Use **Cookie settings** to change the choice later.

The optional local visit counter runs only after it is allowed. Rejecting optional storage deletes its count. The count stays in local browser storage; no analytics service is used.
