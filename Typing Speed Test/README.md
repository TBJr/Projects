# Typing Speed Test

A 60-second typing exercise that shows remaining time, mistakes, words per minute, and characters per minute. **Try Again** loads another passage and resets the counters.

## Run

Open `index.html` in a browser and start typing. No server or build step is required.

Practice passages are stored in `js/paragraphs.js`; the score is calculated in `js/script.js`. Results are not saved between page loads. The Poppins font is requested from Google Fonts and may fall back when offline.
