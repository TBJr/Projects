# Text typing animation

A CSS-only rotating text effect that cycles through four role labels with a typing cursor animation. `js/script.js` is empty.

## Run

Open `index.html` in a browser. No build step or server is required.

Edit the labels in `index.html`, or change the animation timing in `css/style.css`. The animation currently runs continuously and has no motion-reduction option. The Poppins font is requested from Google Fonts and may fall back when offline.
