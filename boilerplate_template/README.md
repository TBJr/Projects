# Boilerplate Template

Open `index.html` in a browser. The page uses plain HTML and CSS.

It has an introduction, three example cards, setup steps, and a final action section. The links on the page jump to those sections.

Before using it, replace the copy and final button link, then edit the colors at the top of `css/style.css`. The Thomas Brown credit is in a comment near the top of `index.html`.
