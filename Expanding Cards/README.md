# Expanding Cards

A set of photo cards that expand when clicked. Open `index.html` in a browser. The demo uses local HTML, CSS, JavaScript, and image files; no build step or server is required.

The first card references `assets/img/bridge_sea.jpeg`, which is not included in this folder, so its background will be blank until that image is supplied or the path is updated. The other four images are present. Cards respond to mouse or touch clicks; they are not currently keyboard controls.
