## Loaded from external services

Some demos load assets from CDNs or call external APIs. Those responses are not bundled with this repository and remain subject to their providers' terms. Examples include Google Fonts, Font Awesome via cdnjs, Unicons, jQuery, Typed.js, Waypoints, Owl Carousel, OpenCage, JSONPlaceholder, and the QR code service at qrserver.com. The relevant project's README describes any runtime dependency.
