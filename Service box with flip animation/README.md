# Service box with flip animation

Three service cards flip to reveal descriptions when hovered. The effect is implemented in CSS; `js/script.js` contains no behavior.

## Run

Open `index.html` in a browser. No build step or server is required.

The cards use placeholder service descriptions. Their reverse side is triggered by hover, with no separate tap or keyboard control. Icons load from the Font Awesome CDN, and the Poppins font loads from Google Fonts, so those assets need an internet connection.
